# Fixtures MOVA — geração reproduzível
Gerador makeJumpFrames em src/engine/protocols/jump.mjs. Trajetória balística 9.81 m/s², duração e escala normalizada (.42 unidades/m) conhecidas pelo gerador; pés fixos antes/depois do voo, preparação de tronco, 30/60/120 FPS, jitter e falhas. Os cinco fixtures do catálogo usam o motor de detecção, não valores prontos. Origem: código criado neste projeto, sem fotos ou dados de pessoas.
O MOVA Lab inclui experimento separado: desenho humanoide em canvas, alimentado como pixels ao MediaPipe Pose Landmarker real. A sequência é codificada localmente pelo MediaRecorder e decodificada pelo HTMLVideoElement, com timestamps de mídia observados; não é referência temporal exata do gerador. Modelo pode falhar, não pontua e não usa ground truth como previsão. A demo pública principal ainda é replay de landmarks; pipeline completo vídeo -> modelo -> métrica experimental, com homologação pendente. Para reproduzir matemática: node benchmarks/synthetic-jump.mjs. Para experimento: /lab, clicar Testar inferência; registrar navegador, contagem, latência e falhas. Nunca publicar dados reais.
