# Fixtures iniciais (geradas para MOVA)
As cinco fixtures declaradas em src/engine/replay/synthetic.mjs são eventos temporais artificiais, sem pessoas, imagens ou vídeos. O replay SVG é esquemático, não mostra landmarks inferidos. A API calcula a altura pela fórmula de tempo de voo, a partir dos eventos do catálogo; o cliente não fornece valor. O cenário feet-cut é rejeitado conforme a anotação sintética. Isso testa fluxo e matemática, não detecção de eventos, nem qualidade automática. A Pessoa 1 deverá entregar CV04/CV12 (clipes sintéticos e motor de protocolo) para a demo integral.
